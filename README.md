# Analises-Estatisticas-no-Futebol-usando-Pandas
Projeto desenvolvido na faculdade onde foi feito um desenvolvimento de um algoritmo em Python, utilizando a biblioteca Pandas, para a análise de dados de partidas do Campeonato Brasileiro Série A, ocorridas entre 2003 e 2023.

O arquivo python fornecido está no formato .ipynb, para a visualização correta do algoritmo deve-se ter o programa 'Jupyter Notebook' instalado no PC.
